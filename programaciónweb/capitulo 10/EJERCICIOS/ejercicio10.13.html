EJERCICIO 10.13

Etiquete los elementos del arreglo bidimensional de tres por cinco llamado ventas para indicar el orden en el que se deben establecer en cero mediante el siguiente segmento de programa:

for ( var fila in ventas )
{
   for ( var col in ventas[ fila ] )
   {
      ventas[ fila ][ col ] = 0;
   }
}

El ciclo externo recorre las filas y el ciclo interno recorre las columnas de cada fila, así que el orden es por filas (el número indica en qué lugar se establece en cero cada elemento):

[ 0 ][ 1 ][ 2 ][ 3 ][ 4 ]
ventas[ 0 ]12345
ventas[ 1 ]678910
ventas[ 2 ]1112131415
