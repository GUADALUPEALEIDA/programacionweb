EJERCICIO 10.7

Indique si cada uno de los siguientes enunciados es verdadero o falso. Si es falso, explique por qué.

  • a) Para hacer referencia a una ubicación o elemento en particular en un arreglo, especificamos el nombre del arreglo y el valor del elemento.
    Falso. Se especifica el nombre del arreglo y el número de posición (índice) del elemento, no su valor.
  • b) La declaración de una variable reserva espacio para un arreglo.
    Falso. Declarar la variable solo crea el nombre; el espacio para los elementos se reserva al crear el arreglo con el operador new o con una lista inicializadora.
  • c) Para indicar que deben reservarse 100 ubicaciones para el arreglo entero p, el programador debe escribir la siguiente declaración: p[ 100 ];
    Falso. Se debe escribir var p = new Array( 100 );. La instrucción p[ 100 ]; sólo haría referencia al elemento 100.
  • d) Un programa de JavaScript que inicializa los elementos de un arreglo de 15 elementos en cero debe contener cuando menos una instrucción for.
    Falso. También puede hacerse con una lista inicializadora (var a = [ 0, 0, 0, ... ];) o con instrucciones de asignación individuales, o con un while o un for...in.
  • e) Un programa de JavaScript que calcula el total de un arreglo bidimensional debe contener instrucciones for anidadas.
    Falso. Lo más común es usar ciclos anidados, pero también pueden usarse otros ciclos (while o for...in) o incluso sumar los elementos con instrucciones individuales.
