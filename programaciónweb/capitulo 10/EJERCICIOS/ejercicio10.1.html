EJERCICIO DE AUTOEVALUACIÓN 10.1

Complete las siguientes oraciones:

  • a) Es posible almacenar listas y tablas de valores en arreglos.
  • b) El número que se utiliza para referirse a un elemento específico de un arreglo se conoce como su índice.
  • c) El proceso de poner en orden los elementos de un arreglo se conoce como ordenamiento el arreglo.
  • d) Al proceso de determinar si un arreglo contiene cierto valor clave se le conoce como búsqueda el arreglo.
  • e) Un arreglo que utiliza dos índices se conoce como arreglo bidimensional.
