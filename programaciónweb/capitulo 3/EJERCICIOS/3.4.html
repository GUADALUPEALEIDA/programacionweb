EJERCICIO 3.4

Indique si cada uno los siguientes enunciados es verdadero o falso. Sí es falso, explique por qué

    a) Los navegadores que despliegan el tipo input color como campo de texto requieren que el usuario introduzca el nombre de un color

    VERDADERO O FALSO

    FALSO PORQUE: Requieren un código hexadecimal, no el nombre de un color.

    b) Cuando un usuario introduce datos en un formulario y luego lo envía (por lo general, al hacer clic en el botón Enviar), el navegador verifica de inmediato que los datos sean correctos.

    VERDADERO O FALSO

    c) HTML5 puede validar si la dirección de correo electrónico introducida por el usuario existe en realidad.

    VERDADERO O FALSO

    FALSO PORQUE:HTML5 solo valida el formato, no si la dirección existe realmente

    d) Puede agregar required a cualquiera de los tipos input.

    VERDADERO O FALSO

    e) Puede habilitar autocomplete sólo para ciertos elementos input.

    VERDADERO O FALSO

    FALSO PORQUE:Puede habilitarse para todo el formulario o para elementos específicos.

    f) El elemento time nos permite identificar una fecha, hora o ambas.

    VERDADERO O FALSO

    g) El elemento caption proporciona una leyenda para la imagen en un elemento figure.

    VERDADERO O FALSO

    FALSO PORQUE:Es el elemento figcaption el que proporciona la leyenda, no caption ese es para tablas

    h) El elemento details muestra una flecha que apunta a la derecha enseguida de un resumen
    o leyenda cuando el documento se despliega en un navegador. Al hacer clic en la flecha, ésta apunta hacia abajo y revela el contenido del elemento summary

    VERDADERO O FALSO

    i) El elemento footer describe el contenido que por lo general aparece en la parte inferior del contenido o del elemento section.

    VERDADERO O FALSO

    j) El elemento highlight nos permite resaltar texto.

    VERDADERO O FALSO

    FALSO PORQUE:No existe el elemento highlight; es el elemento mark el que resalta texto
