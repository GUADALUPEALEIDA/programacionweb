EJERCICIOS DE AUTOEVALUACIÓN

Complete las siguientes oraciones

    a) El elemento __hr___ inserta una regla horizontal.

    b) Para marcar un superíndice se utiliza el elemento __sup____ y para marcar un subíndice se utiliza el elemento __sub____.

    c) El elemento de encabezado menos importante es __h6____ y el elemento de encabezado más importante es __h1____.

    d) El elemento __ul____ marca una lista desordenada.

    e) El elemento __p____ marca un párrafo.

    f) El atributo __type = "reset"____ en un elemento input inserta un botón que, cuando se presiona, restablece el contenido del formulario.

    g) El elemento __tr____ marca una fila de una tabla.

    h) Los __Asteriscos____ se usan por lo general como caracteres de enmascarado en un cuadro de contraseña.
